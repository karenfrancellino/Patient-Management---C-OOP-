## 📌 About the Project

This is a simple C++ console application that manages a list of patients using Object-Oriented Programming (OOP).

The user can input patient data and the system displays a formatted list.

---

## 🚀 Features

- 🧱 Object-Oriented Programming (class `Paciente`)
- 🔒 Encapsulation (private attributes)
- 📝 Data input with `getline`
- 📊 Array of objects
- 📋 Patient listing

---

## 🛠️ Technologies

- C++
- Standard Library (`iostream`, `string`)

---

## 💻 How it works

1. User enters data for 3 patients
2. Each patient is stored in an object
3. The program displays a formatted list
